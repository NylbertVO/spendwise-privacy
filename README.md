
# SpendWise 💸

### A Simple Personal Expense Tracker

SpendWise is a personal finance project designed to help users track daily expenses, manage income, organize budgets, and review their financial activity in one place.

🌐 **Live Website:** https://nylbertvo.github.io/spendwise-privacy/

---

## ✨ Features

- 💸 **Expense Tracking** — Record daily expenses.
- 💰 **Income Tracking** — Keep track of income.
- 📊 **Budget Management** — Organize spending with budgets.
- 🧾 **Transaction History** — Review recorded transactions.
- 📈 **Spending Summaries** — Review financial activity.
- 📤 **Data Export** — Export records in JSON or CSV format.
- 📥 **Data Import** — Import JSON backups.
- 🔒 **Local Storage** — The reviewed web app source stores data in browser local storage on your device.

2. Download or clone the repository.
3. Open `index.html` in your browser.

The static website files do not require package installation.

## 🔐 Privacy

The reviewed web app source stores information in browser local storage on your device. Local storage is not a backup, so export your records regularly.

Read the [Privacy Policy](https://nylbertvo.github.io/spendwise-privacy/privacy-policy.html) for more details.
